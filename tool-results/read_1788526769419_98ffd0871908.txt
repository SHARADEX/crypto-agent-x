    17→   bounties from real orgs). Scam detection correctly rejected fake-airdrop

    24→   code decides. Kill switch (3 mechanisms), policy engine, budget caps,
    25→   idempotency records, read-only wallets (no private keys ever), prompt-
    26→   injection sanitizer, scam detector. 362 tests passing upstream.
    27→4. **Economics are honest.** EXPECTED vs VERIFIED earnings never mixed;
    28→   payments verified on-chain via read-only wallet monitoring (5 chains).

    30→## The caveat: the earnings bottleneck is EXECUTION, not discovery
    31→

    33→submission** for most opportunity types. The GitHub PR adapter is real code
    34→(mock-tested), and the worklog shows the intended path: low-risk GitHub bounty
    35→($50–200, riskScore < 30) → agent generates code → human approves → PR
    36→submitted with GH_PAT → monitor merge → verify payment on-chain.
